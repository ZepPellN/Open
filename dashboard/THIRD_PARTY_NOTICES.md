# Source and attribution

Open Dashboard is an independent implementation inspired by the dashboard
workflow in the source post: https://weibo.com/1727858283/Rmab9bGz4.

It does not contain recovered Claude source or the author's unpublished
attachment. Its source, installer and synthetic example are MIT-licensed;
see LICENSE. The browser runtime does not bundle a third-party charting library.
Python and Node.js are external runtimes, not redistributed here. pandas is
an optional external analysis dependency, not part of the browser deliverable.
